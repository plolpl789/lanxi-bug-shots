# lanxi-bug-shots

**蓝汐**（QQ 群机器人）的 bug 反馈截图存档库 —— 供 GitHub issue 引用。

## 为什么需要这个库

QQ 群友反馈软件问题时常常附截图，但腾讯的图片链接带 `rkey`，**几小时到几天就会失效**。
蓝汐会在收到消息的当下把图片转存到这里，这样写进 issue 的截图**永久可见**。

## 目录规则

```
<群号>/<YYYY-MM-DD>/<bug编号>-<序号>.<ext>
```

例：`540371168/2026-09-10/bug7-1.png`

## 谁来写

只有蓝汐的自动化流程会向本库提交文件，不接受人工 PR。

## 隐私说明

截图由群友在 QQ 群内公开发布，用于向开发者反馈问题。
若你是截图当事人且不希望图片被公开，请开 issue 说明，我们会移除对应文件。
